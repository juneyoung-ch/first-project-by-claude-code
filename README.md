# FIELD NOTES — 현장에서 시작하는 기획

HTML과 CSS로 만든 반응형 개인 소개 웹사이트입니다. 별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

## 내용 수정

- `index.html`: 소개, 프로젝트 상세, 경력 타임라인, 언어·학습 내용과 가치관을 수정할 수 있습니다.
- 제공된 2026-09-21 통합 컨텍스트를 바탕으로 작성했습니다. 재직 상태는 해당 기준일로 표시하며, 학교 프로젝트·사회복무·경찰 근무·개인 실습을 구분했습니다.
- 이름과 연락처가 원문에 없어 임의로 추가하지 않았습니다. 공개하려는 이름과 연락처가 정해지면 헤더와 마지막 섹션에 추가할 수 있습니다.
- 프로젝트의 ‘경험 자세히 보기’를 누르면 문제·역할·결과를 펼쳐 볼 수 있습니다.
- `style.css`: 색상, 여백, 글꼴, 모바일 화면 스타일을 수정할 수 있습니다.

Google Fonts를 불러오며, 인터넷에 연결되지 않으면 시스템 기본 글꼴로 표시됩니다. 원본 컨텍스트 파일은 저장소에 복사하지 않았습니다.

## 로컬 미리보기

`index.html`을 브라우저에서 직접 열거나, Python이 설치되어 있으면 프로젝트 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요.
